# Security Policy

## Supported Versions

We supply updates and patches in the latest release. Update to the latest version of this package.

| Version | Supported          |
| ------- | ------------------ |
| 3.7.x   | :white_check_mark: |

Apps on React Native earlier than 0.82 use `@approov/approov-service-react-native` 3.5.x, which has its own security policy.

## Reporting a Vulnerability

Thank you for telling us about possible security vulnerabilities in this project.
Do not publish details in a public issue or PR. Send a private email to support@approov.io. Tell us which version your report is about.

We will reply to your message promptly.
